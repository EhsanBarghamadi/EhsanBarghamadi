### 🏆 Featured Projects

**[Digichera](https://github.com/EhsanBarghamadi/digichera)** — a multi-vendor e-commerce marketplace built with Django. Sellers open their own stores, customers shop across stores with a single cart, and orders are split per vendor automatically at checkout. Stock is re-checked inside an atomic transaction, with row-level locking on PostgreSQL.  
`Django` · `PostgreSQL` · `Pillow` · `Bootstrap`

**[Event Planet](https://github.com/EhsanBarghamadi/event-planet)** — an API-first event management platform built with Django REST Framework. Multi-stage events with a validated status state machine, type-safe dynamic attributes (EAV), role-based permissions, JWT authentication, and auto-generated OpenAPI docs. Fully containerized with Docker.  
`DRF` · `PostgreSQL` · `JWT` · `Docker` · `OpenAPI`

### 🏆 پروژه‌های شاخص

**[Digichera](https://github.com/EhsanBarghamadi/digichera)** — یک مارکت‌پلیس چندفروشنده با جنگو. فروشندگان فروشگاه اختصاصی خود را می‌سازند، مشتریان با یک سبد خرید از چند فروشگاه خرید می‌کنند و در زمان پرداخت، سفارش‌ها به‌صورت خودکار به ازای هر فروشنده تفکیک می‌شوند. موجودی کالا درون یک تراکنش اتمیک دوباره بررسی می‌شود و روی PostgreSQL قفل سطح ردیف اعمال می‌گردد.  
`Django` · `PostgreSQL` · `Pillow` · `Bootstrap`

**[Event Planet](https://github.com/EhsanBarghamadi/event-planet)** — یک پلتفرم مدیریت رویداد با رویکرد API-first و Django REST Framework. رویدادهای چندمرحله‌ای با ماشین حالت اعتبارسنجی‌شده برای وضعیت، ویژگی‌های پویا و نوع‌امن (EAV)، دسترسی مبتنی بر نقش، احراز هویت JWT و مستندات OpenAPI خودکار. کاملاً کانتینری‌شده با Docker.  
`DRF` · `PostgreSQL` · `JWT` · `Docker` · `OpenAPI`
